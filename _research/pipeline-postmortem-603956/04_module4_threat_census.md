# 交付物⑤ 模块 4：威胁模型普查（每层执法件两列表）

> 普查判词：**每层只看见它被设计去看的东西；层间盲区互相假设对方已覆盖，于是自我复制。** 验收判据表同样复制了执法层的盲区（件3 判据=长度/raw/gate/恢复步数/在册量，无模块读列、无章序列——直到威派格才暴露）。

| 执法层 | 抓什么 | 对什么失明（实证） |
|---|---|---|
| verify_gates 57门（--section/c70） | 报告文本 vs 快照/数据合同、字段在场、数值转录 | 章序（无序门）；**模块读经**（查文本不查读）；写作粒度（双章一次 append 照过）；src 语义归属（T8）；「中枢」可提取性（R4①非门） |
| C2 锚块 | 勾选台账×盘上锚、T1 标量、当前章三态 | **会话身份**（四层 `_latest(glob)` 全局发现=T15，L63/69/70/176；L177 注释证明 12:52 同类 bug 已发生过一次只修了一处）；中枢语义（标签混义=R4①）；forbidden_metric 上游缺失只会渲染「?」（R4②）；模块读状态（只内联指令不查台账） |
| update_checklist | checkbox、--evidence-from 数据路径、c70 sidecar | **④ 是否真跑过**（写作步无 --section 证据校验=T2，东材 L408 实证）；① 模块读（=T11）；步文本与场景文档口径漂移（≥3份 vs 1份按需=T16） |
| load_skeleton 台账 | 全转录 Read 事件 endswith 匹配 | **自己被执行**（设计「hook 内自动跑」、实现只打印命令、实测 0 次=1c）；context 逐出（读过≠在场，锚块自认）；compact |
| generate_checklist（骨架/步文本） | 静态渲染 | 一切动态；步文本可被 grep 进 context 却不被执行（威派格 4 次指令在场 8 次跳读） |
| token_audit | chars/轮次/覆盖率/手写 | 语义正确性（raw 分子由 baked 命令产生=v3-r1 修的量纲失义）；**narration 漂移**（300450「研报 PDF 3 份 ✓」把覆盖数说成下载数，审计无感） |
| atomic_step_probe | Read↔勾 配对 | 配对≠该读未读执法；post-compact 跳读只计数不拦截；跨会话工件 |
| 场景文档（s35 等） | 端点/降级/质量指标 | 质量指标量 presence 非 usefulness（layer2「4字段全有」94% vs 实际 2/4 噪音+免责声明错位）；文档-引擎步文本矛盾（T16） |

**盲区自我复制的机制**：每层的「已覆盖」假设建立在相邻层的职责描述上，而职责描述活在各自文档里——没有任何一层做「跨层不变量」（如：①读经→③写出的闭环）。修复方向不是加第 9 层，而是给 2-3 个**跨层不变量**装机械闸（T11 读经闸、T2 ④证据闸、T15 会话域绑定），并把本普查表固化为验收判据的出题源（新列必须从「失明」列取，不从「抓什么」列取）。
