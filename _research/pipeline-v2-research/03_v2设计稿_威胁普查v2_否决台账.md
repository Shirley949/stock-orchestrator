## 4d 威胁模型普查 v2：10 层两列表（强制重跑件，已跑）

> v1 公理不变：**每层只看见它被设计去看的东西；盲区自我复制。** 本表对 v2 设计重跑；「新盲区」列全部附对策或显式接残。

| 层 | 该层被设计去看的 | v2 设计新增盲区 → 对策 |
|----|----------------|----------------------|
| L1 恒驻层（CLAUDE.md/memory） | 跨会话行为规约 | 预算线/E2E 权重等**数字合同进加载层=化石风险** → 数字只落 engine（update_checklist/gate），加载层只留指针（介质公理） |
| L2 入口层（SKILL.md JIT 表） | 模块加载路由 | **条件态外置后 JIT 表漏列 cases=条件态永不读**（比 v1 更隐蔽：v1 全文在手至少可见）→ JIT 表契约测试：cases 文件必须被索引行引用（grep 断空必验）；触发信封字段**缺失≠false**（北交所 SECUCODE 教训）→ 字段三态化 |
| L3 场景面 | 拉数/降级链 | 预算执法只见 view chars；**scene 侧降级重试（curl→akshare）不产生 view chars=不可见** → 接残：scene 侧浪费归 runner 快照体积监控，不入本判据 |
| L4 模块面 | 合同密度 | kernel↔cases **两文件漂移**（单一真相源被切分）→ 契约测试对拍键名（regression 挂载）；cases 头版本指针 |
| L5 锚块/C2 注入层 | 续接状态重建 | T15+T12 落地后余量 ~180B：**无 MAX_BYTES 断言测试=下次加字段即爆** → 渲染 fixture（归档真工件）＋断言进回归；注入器 glob 跨会话错挂=T15 本体（P1） |
| L6 checklist/骨架层 | 勾选/章序/台账 | load_skeleton 删除后**该读未读全押 transcript 扫描 regex——emoji/Edit 标题漏检前科**（章序失守教训同族）→ 扫描器 fixture 三形态（Edit/heredoc/emoji）两极；DAG 依赖表必须导入硬链清单，未声明依赖=静默假阴 → 硬链盘点为 V2-5 前置任务 |
| L7 runner/snapshot 层 | 数据供给 | --quiet 过度静默→模型补偿性取数（**挤 water bed**）→ 保留 --status 诊断通道；liveness 与诊断分离 |
| L8 gate 层 | 数据合规 | **n-gram 探针抓不住有损转写**——威 §五 恰是有损摘要，单 n-gram=漏报威案 → 双探针强制并置（V2-6）；本层自捕本设计缺陷=普查强制价值的当场证明 |
| L9 token_audit/probe 计量层 | 取数/恢复度量 | ① subagent/fork usage 不入主 transcript→E2E 低估 → 判据票禁 subagent 取数或合并计量（预注册条款）；② **恢复质量归一化分类器是启发式，可能洗白真衰减** → 豁免白名单只含「报告自源 grep」，重拉/错误轮永不豁免 |
| L10 重放/审计层 | 零信任重放 | 「读了却不用/用了却没读」只见于 L8 内容列；L8∩L10 交界=v1 威派格盲区**原址** → V2-6 落地后须用威 §五 重放自证（n-gram 假阴＋比值真阳的两极演示）才算闭环 |

**普查结论**：v2 设计十处新面中 3 处当场发现设计缺陷（L5 断言缺失、L6 扫描器单点、L8 单探针漏报），全部回写 V2-1/V2-2/V2-5/V2-6 对策。普查未跑则这 3 处带病上线——「普查未跑=方案未完成」成立。
